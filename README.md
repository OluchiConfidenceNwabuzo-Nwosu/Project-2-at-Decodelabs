# Project-2-at-Decodelabs
Project 2 was an Exploratory Data Analysis. The goal was to identify patterns and trends within the dataset, calculate basic statistics.

## Tool Used
Microsoft Excel

## Project Task
The dataset was cleaned the previous week and ready for analysis;

I created a statistics table to calculate the mean(avaerage), median, mode, sum, maximum, minimum of the unit price, quantity, total price, items in the cart and order ID;

I created another sheet to pivot analyze my data in order to see the trends and patterns- product trend, referral trend, payment method trend and order status trend.

I represented the trends in a dashboard for easy visualization.

## Insights On Trends
The printer was the most ordered product; a total of 250 orders were cancelled and only 231 orders delivered out of 1200 orders: Instagram was the highest referral source and online payment being the highest payment method.
